# Instruções obrigatórias para Claude

Antes de analisar, gerar ou alterar código de qualquer backend da uliving, leia integralmente:

<https://github.com/uliving-student/.github/blob/main/profile/BACKEND_STANDARDS.md>

Em seguida, leia o `CLAUDE.md` e o `AGENTS.md` existentes na raiz do backend afetado. Instruções de
prompt não substituem o padrão global.

Se o documento canônico não estiver acessível, não altere o código. Informe o bloqueio e solicite
acesso ou uma cópia atualizada.

Depois de rebase, merge, troca de branch ou retomada de trabalho iniciado por outra pessoa ou agente,
releia as instruções, inspecione o diff e execute os testes arquiteturais antes de continuar.

Este arquivo protege trabalhos feitos diretamente no repositório `.github`. Para carregamento
automático em outro backend, esse backend também deve manter um `CLAUDE.md` na própria raiz apontando
para o padrão canônico.
