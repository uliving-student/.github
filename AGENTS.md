# Instruções para agentes — repositório organizacional

Antes de analisar ou alterar qualquer backend da uliving, leia integralmente o padrão canônico:

<https://github.com/uliving-student/.github/blob/main/profile/BACKEND_STANDARDS.md>

Depois leia o `AGENTS.md` local do repositório afetado. O padrão global prevalece; o arquivo local
mantém somente responsabilidades, riscos e exceções específicas do serviço.

Se o padrão canônico não estiver acessível, não altere código de backend. Informe o bloqueio e peça
acesso ou uma cópia atualizada.

Após rebase, merge, troca de branch ou retomada de trabalho de outro agente, releia as instruções e
execute os testes arquiteturais aplicáveis antes de continuar.
